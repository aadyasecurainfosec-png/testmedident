Email settings

Every "Email prescription" now generates a real PDF of the prescription first. By default, it downloads that PDF and opens Gmail in a new tab pre-filled with the patient's email and message — the doctor attaches the downloaded PDF and clicks Send themselves (browsers don't allow a webpage to attach files to Gmail automatically, so this one step can't be skipped). To send fully automatically instead, with the PDF attached and no click needed, create a free account at EmailJS.com, set up an email service + template there, and paste the three IDs below. Leave blank to keep using the Gmail + manual-attach option.

For the PDF to attach automatically: in your EmailJS template editor, add an Attachment field and set its variable name to exactly attachment. Without this, EmailJS will still send the text, just without the PDF attached.
